## Key question 1: Native selection and editing (select all keys of a property/layer/comp, multi-key value edits, fine/coarse drags, Properties panel, U/UU/E/EE, keyframe icons, hold/roving, J/K navigation, add-keyframe-to-many shortcuts, delete-all, Time-Reverse, copy/paste rules, paste-to-many-layers, cross-comp paste, Paste with Property Links, Edit Value dialog, mouse vs keyboard moves, Smoother, Convert Expression/Audio to Keyframes, Keyframe Assistant menu)

### Takeaway
AE's native bulk-editing model is: select keyframes (click a property name for all its keys, Ctrl/Cmd+Alt+A for all *visible* keys, right-click for Select Equal / Previous / Following), then apply one operation to the whole selection. Dragging (scrubbing) a value with many keys selected applies the *same delta* to every selected key; typing a number sets every selected key to that *absolute* value; Comp-panel drags apply the delta. Copy/paste is one-layer-at-a-time on the copy side, pastes with the earliest key at the playhead, and matches properties by name or by data type (one-to-one when the target property differs). There is no native "select all keyframes in the comp", no native keyframe-by-type selection, no relative-offset numeric entry, and Time-Reverse ignores non-contiguous selections, which is exactly where scripts step in.

### Cited Findings

**Setting keys and the stopwatch**
- Clicking the stopwatch next to a property enables keyframing and "creates a keyframe at the current time for that property value"; thereafter "After Effects automatically sets or changes a keyframe for the property at the current time whenever you change the property value." If the stopwatch is off, "that value remains the same for the duration of the layer." — [Adobe Help: Setting, selecting, and deleting keyframes](https://helpx.adobe.com/after-effects/using/setting-selecting-deleting-keyframes.html)
- Keyframes can be added without changing the value via the keyframe navigator check box or "Animation > Add [x] Keyframe, where [x] is the name of the property you are animating." — [Adobe Help](https://helpx.adobe.com/after-effects/using/setting-selecting-deleting-keyframes.html)
- "After you set the initial keyframe for a property, After Effects displays the keyframe navigator. You can use the keyframe navigator to move from keyframe to keyframe or to set or remove keyframes." A filled diamond in the navigator box means "the current-time indicator lies precisely at a keyframe for that layer property"; an empty box means it is between keyframes. — [Adobe Help](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/animation-keyframes/setting-selecting-deleting-keyframes.html)
- Auto-keyframe mode: "To turn auto-keyframe mode on, select Enable Auto-keyframe from the Timeline panel menu. When Auto-keyframe mode is enabled, modifying a property automatically activates its stopwatch and adds a keyframe at the current time." It is off by default and "doesn't automatically activate the stopwatch for properties that aren't interpolated, such as menus, checkboxes, and the Source Text property." — [Adobe Help](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/animation-keyframes/setting-selecting-deleting-keyframes.html); an older Adobe forum thread notes the auto-keyframe stopwatch was removed from the master-switches dock and is reached through the panel menu — [Adobe forums thread 2260167](https://forums.adobe.com/thread/2260167)
- Add/remove a keyframe at the current time for a transform property: "Alt + Shift + property shortcut" (Windows) / "Option + property shortcut" (macOS); P is the Position property shortcut, so Alt+Shift+P / Option+Shift+P on Position. — [Adobe Help: keyboard shortcuts reference](https://helpx.adobe.com/after-effects/desktop/get-started/keyboard-shortcuts/keyboard-shortcuts-reference.html)

**Deleting keys**
- Deactivating the stopwatch deletes all keys: "When you select the stopwatch button to deactivate it, keyframes for that property are permanently removed, and the value of that property becomes the value at the current time. You cannot restore deleted keyframes by clicking the stopwatch button again." Individual keys: select and press Delete. — [Adobe Help](https://helpx.adobe.com/after-effects/using/setting-selecting-deleting-keyframes.html)
- "Pressing Delete removes selected keyframes." — [Adobe Help: shortcuts](https://helpx.adobe.com/after-effects/desktop/get-started/keyboard-shortcuts/keyboard-shortcuts-reference.html)

**Selecting keyframes**
- "Select all visible keyframes and properties: Ctrl+Alt+A (Windows) or Command+Option+A (macOS)." — [Adobe Help: shortcuts](https://helpx.adobe.com/after-effects/using/keyboard-shortcuts-reference.html)
- There is no single shortcut to select every keyframe in a composition; Adobe staff said so in the thread, and a commenter noted "only those keyframes your eyeballs can view will be affected by the CTRL+ALT+A shortcut" (i.e., only revealed properties). A user pointed to Zack Lovatt's free "selectKeysInWorkArea" scriptlet as the workaround. — [Adobe Community: Select all keyframes in a composition](https://community.adobe.com/t5/after-effects-discussions/select-all-keyframes-in-a-composition/m-p/9686516)
- A related thread asks for a shortcut to select all keyframes of a layer; the community's practical answer is reveal with U then marquee/Ctrl+Alt+A. — [Adobe Community: shortcut to select all keyframes for a layer](https://community.adobe.com/t5/after-effects-discussions/is-there-a-shortcut-in-after-effects-to-select-all-keyframes-for-a-layer/m-p/8897994)
- "To select all keyframes for a property that have the same value, right-click (Windows) or Control-click (Mac OS) a keyframe, and choose Select Equal Keyframes." "To select all keyframes that follow or precede a selected keyframe, right-click ... and choose Select Previous Keyframes or Select Following Keyframes." The Select Previous/Following commands "aren't available if more than one keyframe is selected." — [Adobe Help: Setting, selecting, and deleting keyframes (ae_ar locale copy)](https://helpx.adobe.com/ae_ar/after-effects/desktop/animate-in-after-effects/animation-keyframes/setting-selecting-deleting-keyframes.html)
- Users report there is no built-in "select next/previous keyframe" command: one user "edited their keyboard shortcuts for 'select next keyframe' and 'select previous keyframe', but using them does nothing"; a community script that "selects the keyframe right under the CTI for all selected properties" is the workaround. — [Adobe Community: Next/previous keyframe keyboard shortcut](https://community.adobe.com/t5/after-effects-discussions/next-previous-keyframe-keyboard-shortcut/m-p/3660583); [Adobe Community: select next keyframe in selected property script](https://community.adobe.com/t5/after-effects-discussions/select-next-keyframe-in-selected-property-script/td-p/6294533)
- To deselect keyframes without deselecting layers: select all, press U to reveal keys, then Alt-drag a marquee over them. A blue outline on a keyframe means it is selected; clicking elsewhere in the timeline clears the selection. — [Adobe Community: Select property but not keyframes](https://community.adobe.com/t5/after-effects-discussions/select-property-but-not-keyframes/m-p/9162201); [Adobe Community: keyframe selection is off](https://community.adobe.com/questions-529/keyframe-selection-is-off-47090)
- Revealing properties: "To show only properties with keyframes or expressions, press U or select Animation > Reveal Animating Properties." — [Adobe Help: Setting, selecting, and deleting keyframes](https://helpx.adobe.com/after-effects/using/setting-selecting-deleting-keyframes.html)

**Editing a value with several keys selected (verified against Adobe's help excerpts)**
- Dragging (scrubbing) the underlined value with multiple keyframes selected "shifts every selected keyframe by that same amount" (a relative change). Entering a value numerically "makes every selected keyframe take the new value exactly" (absolute). Drags in the Composition or Layer panel also apply the difference: Adobe's example is dragging one Position keyframe 10 pixels left, and the other selected keyframes move 10 pixels left too. Constraint: "All keyframes you select must belong to the same layer property." — [Adobe Help: Editing, moving, and copying keyframes](https://helpx.adobe.com/after-effects/using/editing-moving-copying-keyframes.html)
- Caution: "If you change a property value while the Current Time Indicator is not on an existing keyframe, After Effects adds a new keyframe." If you double-click a keyframe to modify it, the CTI position "isn't relevant, nor is it relevant when you change the interpolation method of a keyframe." — [Adobe Help: Setting, selecting, and deleting keyframes](https://helpx.adobe.com/after-effects/using/setting-selecting-deleting-keyframes.html)
- Fine/coarse scrubbing of hot-text values: "Hold down CTRL and you scrub, to change values via single decimal digits. Hold down SHIFT while scrubbing, to change values by values of 10s. Without a modifier key, value changes are in integers." — [Adobe Community: hot text behaviour vs Premiere](https://community.adobe.com/t5/after-effects-discussions/can-i-get-the-quot-hot-text-quot-to-work-the-way-it-does-in-premiere/m-p/9616381)
- Edit Value dialog: "Right-click (Windows) or Control-click (macOS) the keyframe. The keyframe value appears at the beginning of the context menu that appears. Choose Edit Value to edit the value, if desired." Alternative: "Move the Current Time Indicator to the time of the keyframe. The value of the property appears next to the property name, where you can edit it." — [Adobe Help: Setting, selecting, and deleting keyframes](https://helpx.adobe.com/after-effects/using/setting-selecting-deleting-keyframes.html)
- Graph Editor bulk transform: "In the Graph Editor, you can move the selected keyframes in time or value by dragging the bounding box or its handles. Adjusting that box in a value graph moves the selected keyframes in time and value." — [Adobe Help: Editing, moving, and copying keyframes](https://helpx.adobe.com/after-effects/using/editing-moving-copying-keyframes.html)

**Moving keyframes in time**
- "Alt+Left/Right Arrow (Option on Mac) moves selected keyframes one frame earlier or later, and Alt+Shift+Left/Right moves them 10 frames." "Alt+Shift+J opens the 'Go to specific time' dialog." — [Adobe Help: shortcuts](https://helpx.adobe.com/after-effects/desktop/get-started/keyboard-shortcuts/keyboard-shortcuts-reference.html)
- Navigation: "J and K jump to the previous or next visible item in the time ruler, which includes keyframes, layer markers, and work area edges" ("Go to previous or next visible item in time ruler", same keys on both platforms). The keyframe navigator arrows do the same per property. A Shift+J/K variant limited to "keyframes and markers of selected layers and properties" is described in Adobe's preview page per the search excerpt (treat as needing verification in the current build). — [Adobe Help: shortcuts](https://helpx.adobe.com/after-effects/desktop/get-started/keyboard-shortcuts/keyboard-shortcuts-reference.html); [Adobe Help: Preview without rendering](https://helpx.adobe.com/after-effects/using/previewing.html)

**Keyframe icons and interpolation states**
- Diamond = default linear; applying Easy Ease on both sides "transformed [the diamonds] into an hourglass shape"; arrows denote one-sided easing; Ctrl/Cmd-click a keyframe "to switch it to linear, and if it makes an Auto Bezier (circle), ctrl + left click one more time". — [UT Austin KB: Keyframes, the very basics](https://sites.la.utexas.edu/kb/2021/04/09/keyframes-the-very-basics/); [Adobe Community: what are these keyframe icons](https://community.adobe.com/t5/after-effects-discussions/what-are-these-keyframe-icons/m-p/13076806)
- Hold interpolation: "If you apply Hold temporal interpolation to all keyframes of a layer property, the value of the first keyframe holds steady until the next keyframe, when the values change immediately"; useful for strobes or sudden appear/disappear. "Toggle Hold Keyframe" in the keyframe menu "holds the property value at the value of the current keyframe until the next keyframe is reached." — [Adobe Help: Keyframe interpolation](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/animation-keyframes/keyframe-interpolation.html)
- Roving: "Roving keyframes are available only for spatial layer properties, such as Position, Anchor Point, and effect control points"; a keyframe "can rove only if it isn't the first or last keyframe in a layer." The Keyframe Interpolation dialog's Roving menu offers Current Settings, Rove Across Time ("smooths the rate of change through the selected keyframes by automatically varying their position in time, based on the positions of the keyframes immediately before and after the selection") and Lock To Time. Interpolation "cannot change the actual duration between keyframes." — [Adobe Help: Keyframe interpolation](https://helpx.adobe.com/after-effects/using/keyframe-interpolation.html); [Adobe Help: Apply and control speed changes](https://helpx.adobe.com/after-effects/using/speed.html)
- Keyframe Interpolation dialog is opened on a selection via Animation > Keyframe Interpolation (shortcut Ctrl+Alt+K per the shortcuts page) or the keyframe context menu, and acts on all selected keyframes; "Current Settings" leaves mixed selections untouched. — [Adobe Help: Keyframe interpolation](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/animation-keyframes/keyframe-interpolation.html)
- Easing shortcuts that act on the whole selection: "Easy ease selected keyframes: F9. Easy ease in: Shift+F9. Easy ease out: Ctrl+Shift+F9 (Windows) or Command+Shift+F9 (macOS). Set velocity for selected keyframes: Ctrl+Shift+K (Windows) or Command+Shift+K (macOS)." — [Adobe Help: shortcuts](https://helpx.adobe.com/after-effects/using/keyboard-shortcuts-reference.html)
- Roving as a design idea: "By using roving keyframes, you can separate space and time. For instance, you can have a complex motion path, but a simple speed curve (or even a constant speed)." — [ProVideo Coalition: After Effects tips installment 3](https://www.provideocoalition.com/after_effects_tips_installment_3/)

**Copying and pasting keyframes**
- Adobe: "you can copy keyframes from only one layer at a time" (stated for copying as tab-delimited text). On paste, keyframes "appear in the corresponding property in the destination layer. The earliest keyframe lands at the current time, and the other keyframes follow in relative order." — [Adobe Help: Editing, moving, and copying keyframes](https://helpx.adobe.com/after-effects/using/editing-moving-copying-keyframes.html)
- "You can copy keyframes between layers for the same property, such as Position, or between different properties that use the same type of data, such as between Position and Anchor Point." "When copying and pasting between the same properties, you can copy from more than one property to more than one property at a time. However, when copying and pasting to different properties, you can copy only from one property to one property at a time." "To paste to the same property of the copied keyframes, select the destination layer. To paste to a different property, select the destination property." — [Adobe Help: Editing, moving, and copying keyframes](https://helpx.adobe.com/after-effects/using/editing-moving-copying-keyframes.html)
- Pasting into multiple selected layers at once: Adobe's page (per excerpts) describes selecting "the destination layer" but does not state whether a single paste fills several selected layers; no reliable source confirming or denying multi-layer paste was found in this run (see Gaps). The third-party "Paste Multiple Keyframes" script exists precisely because native copy "copies whole layers rather than individual keyframes" from multiple layers. — [Lester Banks: Paste Multiple Keyframes from multiple layers](https://lesterbanks.com/2012/08/paste-multiple-keyframes-from-multiple-layers-in-after-effects-with-this-new-ae-script/)
- Dimension data: in the spreadsheet (text) export "property values appear in columns C, D, and E, depending on the dimensions of the property. Position in a 3D layer has values in all three columns – Opacity has only a value in column C." — [Adobe Help: Editing, moving, and copying keyframes](https://helpx.adobe.com/after-effects/using/editing-moving-copying-keyframes.html)
- Separate Dimensions caveat: "If you use the Separate Dimensions command to separate the dimensions of the Position property into individual components, the number of keyframes changes"; recomposing loses motion-path/speed information, so "work with separate dimensions or without separate dimensions for each property for an entire project rather than toggling back and forth." — [Adobe Help: Expression language reference](https://helpx.adobe.com/after-effects/using/expression-language-reference.html)
- Position/Anchor Point keyframes can be pasted into a mask path or shape path: "make sure that you copy keyframes from a single Position property only—don't copy the keyframes of any other property." — [Adobe Help: Managing and animating shape paths and masks](https://helpx.adobe.com/after-effects/using/animating-shape-paths-masks.html)
- Paste with Property Links: "Edit > Copy With Property Links, or Edit > Copy With Relative Property Links", then a normal paste places the properties on any layer "where they stay connected to the layer they came from"; the absolute version writes `comp("source_comp")...` expressions, the relative version `thisComp.layer(...)`; a whole layer can be copied with links to make duplicates that follow the original. — [Adobe Help: Editing expressions](https://helpx.adobe.com/au/after-effects/desktop/work-with-expressions/edit-expressions/edit-expressions.html); used for "effects instancing" (edit one master layer, every pasted copy follows) — [ProVideo Coalition: Hidden Gems, effects instancing](https://www.provideocoalition.com/after-effects-hidden-gems-weekly-effects-instancing/); [Lester Banks: Copy with Property Links](https://lesterbanks.com/tag/after-effects-paste-property-links/)

**Time-Reverse Keyframes**
- "In the Timeline panel, select a range of keyframes you want to reverse. Select Animation > Keyframe Assistant > Time-Reverse Keyframes." Works across layers/properties but "Each set of keyframes for a property is reversed only within its original time range and not that of any other selected property." "Markers in the Timeline panel are not reversed." Layer > Time > Time-Reverse Layer is different: it reverses playback and "All keyframes for all properties on the selected layer also reverse order." — [Adobe Help: Editing, moving, and copying keyframes](https://helpx.adobe.com/after-effects/using/editing-moving-copying-keyframes.html)
- Limitation: with a non-contiguous selection the command "seems to ignore any keyframes selected between the first and the last selected keyframe"; selecting every other keyframe "just reversed the whole keyframe sequence, ignoring my carefully selected subset." A bug report that it "reverses all the keyframes within any selected keyframes, not only the selected keyframes" was closed by Adobe as "Won't fix" / feature request; another expert "am not seeing this behavior" on their version. — [Adobe Community idea: non-continuous selection](https://community.adobe.com/t5/after-effects-ideas/make-time-reverse-keyframes-work-for-non-continuous-selected-keyframes/idi-p/13700353); [Adobe Community bug: should only affect selected keyframes](https://community.adobe.com/t5/after-effects-bugs/time-reverse-keyframes-should-only-affect-selected-keyframes/idc-p/15103795)

**Keyframe Assistants: Smoother, Convert Expression to Keyframes, Convert Audio to Keyframes**
- The Smoother "adds or removes keyframes to smooth motion paths, value curves, and velocity curves"; best on Motion Sketch output, and "Applying it to manually set keyframes may result in unexpected changes to the curve." Steps: "Select all the keyframes for a property to smooth the entire curve or select at least three keyframes to smooth only a portion of a curve", open Window > The Smoother, set Tolerance ("New keyframe values vary no more than the specified value from the original curve. Higher values produce smoother curves, but too high a value may not preserve the original shape"), click Apply; iterate with "Edit > Undo Smoother ... adjust the value for Tolerance, and then reapply." Motion Sketch's Smoothing setting equals the Smoother's Tolerance. — [Adobe Help: Assorted animation tools](https://helpx.adobe.com/au/after-effects/using/assorted-animation-tools.html)
- Convert Expression to Keyframes: "After Effects evaluates the expression, creating a keyframe at every frame, and then turns off the expression." Invoke: select the property, "Animation > Keyframe Assistant > Convert Expression To Keyframes." "The original expression is preserved, only turned off." Use cases: freeze values to hand-edit, or speed up slow expressions. — [Adobe Help: Learn expression basics](https://helpx.adobe.com/after-effects/using/expression-basics.html)
- Convert Audio to Keyframes: right-click the audio layer > Keyframe Assistant > Convert Audio to Keyframes; "After Effects will generate a new null layer named Audio Amplitude, which contains three properties: Left Channel, Right Channel, and Both Channels" (each a Slider); "Both Channels > Slider" is the usual driver and typically needs scaling (`*10`, or `linear()`/`ease()` remaps) because raw values are small; in CC 2017 "values for Both channels of about 11 or 12 for zero DB" were reported. — [AEJuice: sync animation to audio](https://aejuice.com/blog/how-to-link-keyframes-to-audio-in-adobe-after-effects/); [PremiumBeat: using audio to drive motion graphics](https://www.premiumbeat.com/blog/using-audio-drive-motion-graphics/); [Adobe Community: Convert Audio to Keyframes not accurate](https://community.adobe.com/t5/after-effects-discussions/convert-audio-to-keyframes-not-accurate/m-p/8792683)

### Inferences
- Implied native features for the new app: (1) one-click "select all keys of property / of layer / of comp" that is independent of what is revealed on screen (AE's Ctrl+Alt+A only hits visible keys, which is the top complaint in the "select all keyframes" threads); (2) numeric field with explicit **Absolute** and **Offset (+/-)** modes for multi-key edits, since AE splits this invisibly between "type = absolute" and "drag = relative"; (3) modifier-scaled scrubbing (0.1 / 1 / 10 steps) as in AE's Ctrl/none/Shift; (4) selection filters: equal value, before/after a key, by interpolation type, in work area, at playhead; (5) paste that places the first key at the playhead and fans out to every selected layer/property with type-compatibility rules shown up front; (6) Time-Reverse that honours sparse selections; (7) paste-as-link (Property Links) as a first-class "instance" operation; (8) built-in reduce/smooth with a tolerance slider and live preview (The Smoother already models tolerance-based reduction); (9) bake-expression and audio-to-keyframes as one-click assistants writing to a visible driver layer.
- AE's hard constraint that multi-key edits apply only within "the same layer property" is a limitation of its data model, not a UX choice; a new app can apply a delta across heterogeneous properties if units are compatible.

## Key question 2: Scripts and plugins (KeyTweak, Paste Multiple Keyframes, Key Cloner, Smart Key Reverse, Zack Lovatt scriptlets and Easy Bake, EaseCopy, Dojo Shifter/Ease, Motion Tools Pro, Mt. Mograph Motion, KBar, ft-Toolbar, Workflower, reducers/bakers, beHOLD/beKind, select-by-type)

### Takeaway
The third-party ecosystem fills six native holes: proportional multi-key editing (KeyTweak), multi-layer copy/paste and loop-paste (Paste Multiple Keyframes, Key Cloner, Motion's Clone), selection by rule (Zack Lovatt's scriptlets: in work area, at playhead, alternating, saved "Key Sets"), reverse/stagger/offset with options (Smart Key Reverse 2, Dojo Shifter, Motion Stagger/Delay), ease transfer separate from values (EaseCopy, Dojo Ease, Motion Tools Pro Easings Manager), and bake/reduce (Easy Bake, AEJuice Bake Expressions, Keep Every N Keys, Remove Unnecessary Mask Keyframes). Button launchers (KBar, ft-Toolbar) exist to put these behind one click; several of the scriptlets are explicitly designed to be run from KBar with modifier keys.

**KeyTweak (mamoworld, aescripts, name-your-own-price)**

## Key question 3: Navigation and viewing (timeline zoom, fit to comp, jumping between keys, Graph Editor with multiple properties, value vs speed graphs, locking the view, bulk behaviour of the Interpolation/Velocity dialogs, complaints about losing selection or view state)

### Takeaway
AE's navigation is keyboard-heavy and partly undocumented: ; and Shift+; toggle frame view and whole-comp view (sources disagree on which key does which), = and - zoom, J/K jump between visible keys. The Graph Editor shows one curve per property and can show several at once, but the "Show Animated Properties" default makes unrelated curves pile up; the "Fit Selection"/"Fit All"/"Auto Zoom Height" commands live in the Graph Editor menu without documented shortcuts. Users lose keyframe selections when switching to the Graph Editor and (in 24.0) lost layer selection when adding a first keyframe; locked layers still display keys but cannot be edited.

### Cited Findings
- Timeline zoom: Adobe's shortcuts list (as quoted by a community reply) gives "Zoom in Timeline panel to single-frame units (Press again to zoom out to show entire composition duration.) ; (semicolon)" and "Zoom out in Timeline panel to show the entire composition duration (Press again to zoom back in to the duration specified by the Time Navigator.) Shift+; (semicolon)"; another reply says "just ; by itself it a toogle, zoomed out all the way or zoomed in all the way", and another that "SHIFT+; ... is the shortcut for view the entire length of a timeline. It's actually a toggle." "= (main keyboard) zoom in on the timeline and - zooms out. Both act centered on the timeline." — [Adobe Community: timeline zoom to fit](https://community.adobe.com/t5/after-effects-discussions/keyboard-shortcuts-timeline-zoom-to-fit-move-layer-to-playhead/m-p/10227670/highlight/true); [Adobe Community: work area zoom to fill timeline](https://community.adobe.com/t5/after-effects-discussions/shortcut-key-to-have-work-area-zoom-to-fill-timeline-view/m-p/15006230); No Film School: "Press the semicolon key to quickly zoom all the way into single-frame units. Press again to zoom back out." — [No Film School: 25 tips](https://nofilmschool.com/2017/11/25-after-effects-tips-tricks-master-workflow)
- Graph Editor basics: "each property is represented by its own curve. You can view and work on one property at a time, or you can view multiple properties simultaneously." Menu commands: "Fit Selection adjusts the value (vertical) and time (horizontal) scale of the graph to fit the selected keyframes in the Graph Editor. Fit All does the same for all graphs in the editor. Auto Zoom Height is a separate toggle that scales the graph's height to fill the editor." Show Post-Expression Graph is available while showing the value or velocity graph. — [Adobe Help: Animation basics](https://helpx.adobe.com/after-effects/using/animation-basics.html)
- "Shift+F3 toggles between Graph Editor and layer bar modes" (also the Graph Editor button at the top of the Timeline). No documented shortcut for Fit Selection/Fit All or for switching value/speed graphs was found; switching is via the graph-type menu at the bottom of the Graph Editor. — [Adobe Help: shortcuts](https://helpx.adobe.com/after-effects/using/keyboard-shortcuts-reference.html); [Adobe Help: Animation basics](https://helpx.adobe.com/after-effects/using/animation-basics.html)
- Clutter complaint and fix: a user "couldn't isolate one animated parameter in the graph view without the other being in the way"; the working answer was to turn off "Show Animated Properties" (which "displays animated properties of selected layers in the Graph Editor") so that only the selected parameter is framed. Another user saw "the graphs for every effect on a clip" open when only Scale was open, only when multiple effects were applied. Multi-dimensional properties draw one line per dimension (2 for 2D Position, 3 when the layer is 3D). — [Adobe Community: only show selected parameter](https://community.adobe.com/t5/after-effects-discussions/only-show-selected-parameter-in-timeline-graph/m-p/9022523); [Adobe Community: show all graphs instead of one](https://community.adobe.com/t5/after-effects-discussions/after-effects-show-all-graphs-instead-of-one/m-p/10431887); [Adobe Community: graph editor stuck with multiple keyframes](https://community.adobe.com/t5/after-effects-discussions/graph-editor-stuck-with-multiple-keyframes/td-p/11895162)
- Locked layers: a feature request asks to view properties of locked layers (e.g., waveform hidden until unlocked); an expert replied that keyframes and the waveform still display but "you just can't modify the settings while it's locked", and that "all layers show all modified properties when some layers are locked"; workaround: select all layers and collapse the others' property lists. — [Adobe Community idea: view properties of locked layers](https://community.adobe.com/t5/after-effects-ideas/let-us-view-properties-of-locked-layers/m-p/15543995)
- Losing selection: keyframes selected in the timeline "lost their selection after they clicked the Graph Editor button, forcing them to reselect" (an expert asked whether the Speed Graph rather than Value Graph was shown; no confirmed fix). — [Adobe Community: selection not going to graph editor](https://community.adobe.com/t5/after-effects-discussions/after-effects-selected-keyframes-selection-not-going-to-graph-editor/m-p/10764725/highlight/true)
- In After Effects 24.0, "adding a first keyframe with a shortcut deselected the layer, so you had to click it again before keyframing another property"; Adobe said it was fixed in 24.0.1. — [Adobe Community bug: 2024 auto-deselect layer after added keyframe](https://community.adobe.com/t5/bug-after-effects/after-effects-2024-auto-deselect-layer(s)-after-added-keyframe-with-shortcut/idi-p/14159152)
- Jumping between keys: J/K go to the previous/next visible item in the time ruler (keyframe, marker, work-area end); per-property keyframe navigator arrows. — [Adobe Help: shortcuts](https://helpx.adobe.com/after-effects/desktop/get-started/keyboard-shortcuts/keyboard-shortcuts-reference.html)
- Bulk dialogs: Keyframe Interpolation (Animation > Keyframe Interpolation, or right-click a keyframe) changes temporal/spatial interpolation and roving for all selected keys, with "Current Settings" preserving mixed states; "Set velocity for selected keyframes: Ctrl+Shift+K / Command+Shift+K". — [Adobe Help: Keyframe interpolation](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/animation-keyframes/keyframe-interpolation.html); [Adobe Help: shortcuts](https://helpx.adobe.com/after-effects/using/keyboard-shortcuts-reference.html)

### Inferences
- Implied features: a persistent, explicit "pinned" set of curves in the graph view (AE's "Graph Editor Set" toggle approximates this but defaults fight the user); selection state that survives switching between dope-sheet and curve views; Fit Selection / Fit All / frame-view / whole-comp as both buttons and documented shortcuts; a single key that cycles value and speed graphs; locked layers that stay inspectable; J/K-style jumps scoped to the selection.

## Key question 4: Preview and scrubbing hacks that affect the editing loop (Caps Lock, resolution shortcuts, RAM-preview/Preview-panel presets, Shift-scrub, audio scrub, "favors frame rate", responsiveness complaints)

### Takeaway
Caps Lock is AE's universal "stop rendering while I edit" switch (with a long record of bugs around its state), Ctrl/Shift modify scrub step sizes, the Preview panel binds up to seven shortcuts each to its own resolution/skip/frame-rate preset, and viewer resolution has Cmd/Ctrl+J family shortcuts per community sources. Users still complain about scrub lag and about live-update failing; Adobe's answer in recent versions is "uninterrupted preview" (edit while playback continues).

### Cited Findings
- Caps Lock: "pressing the Caps Lock key makes the application stop trying to render/update the contents of the active Composition. It's useful when a frame is slow to render or the Comp panel is sluggish. You can tweak a parameter and see the result once you release the key. To exit this state, just press the Caps lock key again." — [Creative COW forum](https://creativecow.net/?p=214619); it is also used to "keep video from updating" while scrubbing audio to place markers, a trick that "has worked since Version Three". — [Adobe Community: audio scrubbing](https://community.adobe.com/t5/after-effects-discussions/audio-scrubbing/m-p/9759212)
- Caps Lock bugs: in the 24.5 beta the banner "Refersh Disabled (Release Caps Lock to refresh view)" appeared with Caps Lock off; typing any key temporarily cleared it. — [Adobe Community bug: 24.5.0 build 46 caps lock not engaged](https://community.adobe.com/bug-reports-533/adobe-after-effects-beta-24-5-0-build-46-caps-lock-is-not-engaged-904998); AE "forgets that it is pressed when switching Comps" (request to make it persistent). — [Adobe Community: make caps lock persistent](https://community.adobe.com/t5/after-effects-bugs/make-caps-lock-persisitent/m-p/15008692); when scrub preview stops updating, users toggle the Timeline's "Live Update" check mark and Caps Lock a few times. — [Adobe Community: caps lock error message](https://community.adobe.com/t5/after-effects-discussions/caps-lock-error-message/m-p/2206388)
- Alt while scrubbing forces a preview when live update is off: "you can hold down the Alt key while scrubbing for the preview." — [Adobe Community: caps lock error message](https://community.adobe.com/t5/after-effects-discussions/caps-lock-error-message/m-p/2206384/highlight/true)
- Scrub step modifiers (values, not playhead): Ctrl = single decimal digits, Shift = tens, none = integers. — [Adobe Community: hot text](https://community.adobe.com/t5/after-effects-discussions/can-i-get-the-quot-hot-text-quot-to-work-the-way-it-does-in-premiere/m-p/9616381)
- Preview panel presets: "there are a total of seven keyboard shortcuts you can use to trigger a preview. So, rather than changing these parameters every time, you can set up a range of preview presets" via the Shortcut dropdown in the Preview panel; one guide sets Shift so "the RAM preview skips a frame and sets the resolution to half"; an Adobe community manager shows Numpad 0 bound to "always preview in Half res, regardless of my Comp's resolution." — [tutkit: optimal RAM preview](https://www.tutkit.com/en/text-tutorials/16621-optimal-ram-preview-for-after-effects); [Adobe Community: preview](https://community.adobe.com/t5/after-effects/preview/m-p/11099457); [Adobe Community: preview quality higher than wanted](https://community.adobe.com/questions-529/preview-quality-being-higher-than-wanted-60305)
- Viewer resolution shortcuts (student blog, macOS): "Full: Cmd + J - Half: Cmd + Shift + J - Quarter: Cmd + Opt + Shift + J." — [Bucknell practicum blog: keyboard shortcuts](https://practicumfall2017.blogs.bucknell.edu/2017/11/01/quick-review-keyboard-shortcuts); a community reply describes Shift+J as slowing playback ("press Shift+J and it will slow it down"). — [Adobe Community: decrease playback speed](https://community.adobe.com/questions-729/how-to-decrease-playback-speed-in-preview-1406781)
- Adobe's current answer to the edit-while-previewing loop is the "uninterrupted preview" tutorial, "Preview in real time as you make adjustments" (page blocked; title and existence only). — [Adobe Learn: uninterrupted preview](https://www.adobe.com/learn/after-effects/web/uninterrupted-preview)

- Implied features: an explicit, persistent "pause rendering" toggle with visible state (AE's Caps Lock is invisible, mis-detected and forgotten per comp); preset preview profiles (resolution, frame skip, target fps) bound to keys; modifier-scaled scrubbing; live-update that never silently turns off; edits allowed during playback by default.
